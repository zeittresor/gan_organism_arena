GAN Organism Arena portable runtime folder
===========================================

The Windows installer downloads Godot 4.7.2 stable here on first installation.
No system-wide Godot installation is required.

If automatic download is blocked by a proxy/firewall, manually download:
  Godot_v4.7.2-stable_win64.exe.zip
from the official Godot 4.7.2 release and place the ZIP in this folder, then
run install_windows.bat again. The installer verifies the archive SHA-256 before
extracting it.

Expected SHA-256 (Windows x64 ZIP):
731980F9608D61333E5BAF54A2EF17210ACC7A538446C0CB9969F002ACA1E953
